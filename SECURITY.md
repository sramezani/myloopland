# Security

If you find a security problem in myloopland, please report it privately: on GitHub, open the repository's **Security** tab and choose **Report a vulnerability**. Please don't open a public issue for it.

Say what you found, how to reproduce it, and what someone could do with it. You'll get an answer within a few days.

This covers the code in this repository and the hosted site at https://myloopland.com. Please don't test against other people's accounts or data there: use your own account, or run a copy locally (`README.md`).
